# AppifyLab

## Prerequisites

Before getting started, make sure you have the following installed:

- [Bun](https://bun.com) (v1.3.14 or later)

## Installation

Install the project dependencies:

```bash
bun install
```

## Running the Project

Start the application:

```bash
bun run index.ts
```

## Built With

- [Bun](https://bun.com) — Fast, all-in-one JavaScript runtime and toolkit
- TypeScript

## Development

This project was initialized using:

```bash
bun init
```

with **Bun v1.3.14**.
